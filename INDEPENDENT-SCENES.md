# Две независимые сцены для монтажа

Диаграмма и код подготавливаются отдельно. Общая запись окна VS Code не является
фоном: в монтаж не попадают вкладки, разделители панелей и обрезанные рамки редактора.

```powershell
.venv\Scripts\python.exe -X utf8 scripts/render_independent_scenes.py composition.local.json
```

Начните с [примера параметров](examples/independent-scenes.json). Пути разрешаются
относительно JSON. Требуются чистый экспорт диаграммы и `code-source.json` с полями
`code`, `colors` (цвет каждого UTF-16 символа), `lineMap` (номера исходных строк),
`source` (файл кода). Снимок кода проверяется на соответствие исходнику.
Для событий нужны также координаты из `screen-geometry.json` соответствующего
экспорта диаграммы; событие задаёт `time`, `diagramCell`, `codeLine`.

Результаты в новом каталоге `independent-scenes-*` настроенного хранилища:

- `diagram.mp4` — самостоятельная дорожка диаграммы;
- `code.mp4` — самостоятельная дорожка кода с семантическими цветами;
- `composed.mp4` — монтаж этих дорожек в областях, заданных в `tracks`;
- PNG обеих сцен и общего кадра; отчёт с размерами, числом кадров и хешами источников.

Положение и размеры дорожек меняются независимо. Области не могут перекрываться
или выходить за холст. Диаграмма вписывается целиком без обрезки. Размер шрифта
кода подбирается по фактической ширине строк, с нижним пределом
`minimumCodeFontSize` (по умолчанию 18). Если код не помещается, рендер останавливается.

`audio` — необязательный путь к готовому аудио; оно добавляется только в итоговый
монтаж. `durationSeconds` задаёт длину клипа с начала аудио. Дорожки остаются без
звука, чтобы озвучка не дублировалась при монтаже. Ничего не публикуется в таблицу.

Этот путь заменяет общий захват для новых композиций, но не изменяет старые
материалы и `dual-scene`. События пока переключают выделение цели без плавной
анимации. Вписывание целой большой диаграммы предотвращает обрезку, но не гарантирует
читаемость всех подписей: для финального ролика следует заранее экспортировать
нужный смысловой фрагмент из draw.io, сохранив целые узлы и соответствующую геометрию.
