# A11 — статистика цикла Фишера

Сценарий принятого отрезка `scene-interactive-v2.mp4`. Тайминги ниже относятся к итоговому видео, а не к исходной записи OBS. Длительность — 19,833 с.

## Исходное состояние

- VS Code: `graphKoda (Workspace)`, открыта `graph/draw/generated/Fisher-Yates.drawio`, масштаб 50%.
- Видна петля `for`, панель статистики закрыта, чат скрыт. Trace выключен, сохранённые утолщения линий удалены.
- Голова функции: `examples/fisher-yates/src/shuffle.ts:6:7:36:1`.
- Узел цикла: `examples/fisher-yates/src/shuffle.ts:29:1:33:3:for`, визуальный cellId: `f0-n4`.
- Runtime-сессия: `fisher-2edb4fb3-e525-4179-a72c-2b995d8de841`. Ожидается 8 проверок условия: 7 продолжений и 1 выход.
- OBS: сцена «Сцена», холст и выход 1600×900. Захват только окна VS Code, не всего рабочего стола.
- Размер захватываемого окна 1920×1032; обрезка слева 94, сверху 119, справа 232, снизу 16; масштаб 0,872093; положение в холсте (45, 104).

## Действия

| Время в ролике | Действие |
| --- | --- |
| 0–1,939 с | Исходная диаграмма без статистики. |
| 1,939 с, слово «откроем» | Открыть настоящее контекстное меню ПКМ на `f0-n4`. |
| 1,939–3,561 с | После короткой паузы прокрутить меню вниз до команды «показать статистику Цикла»: 8 импульсов колеса по −120 с интервалом 180 мс в исходной записи. |
| 3,561–4,692 с | Навести указатель на видимую команду, выдержать паузу и вызвать её штатный обработчик. Нельзя вызывать скрытый пункт без прокрутки. |
| 4,772 с, слово «Здесь» | Панель статистики загружена; проверено наличие всех 8 кейсов. |
| После загрузки — примерно до 7,630 с | Перетащить левую границу панели влево. Остановиться справа от вертикальной связи repeat с зазором около 35 px в итоговом кадре. |
| До 19,833 с | Оставить панель раскрытой, видны все 8 строк. Не выбирать кейсы и не включать подсветку пути. Увести курсор от содержимого. |

## Координаты действий

Координаты ниже — пиксели относительно **окна VS Code 1920×1032**, не холста видео. Перед повторением проверить размер окна и расположение элементов; при изменении интерфейса пересчитать координаты.

- Прокрутка внутри меню: `(500, 690)`.
- Наведение на команду после прокрутки: `(470, 904)`.
- Перетаскивание разделителя: из `(1000, 570)` в `(720, 570)`, 45 шагов по 20 мс.
- Итоговая граница панели в видео: примерно x=591; repeat: x=556.
- После перетаскивания увести указатель в `(1740, 950)`.
