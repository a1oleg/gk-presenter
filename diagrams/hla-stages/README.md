# Поэтапная схема для видео

- `HLA1-source.drawio` — неизменённый снимок полной `coldKode/graph/draw/HLA1.drawio`.
- `001-code-graph-diagram.drawio` — первый этап для `!C3`: исходники → граф → диаграмма.
- `001-code-graph-diagram.png` — кадр 1600 × 900, экспортированный локальным движком draw.io.
- `001.manifest.json` — происхождение, сохранённые ID и состав этапа.
- `001-check.json` — проверка реального файла через drawio-inspector MCP.

Последующие этапы сохранять новыми нумерованными файлами. Существующие стадии не перезаписывать при добавлении сущностей; сохранять позиции уже показанных элементов, если позволяет композиция. Мастер остаётся отдельно и не упрощается.

Сборка первого этапа: `.venv\Scripts\python.exe scripts/build_hla_stages.py`.
Исходники диаграмм находятся в приватном репозитории presenter; в публичный репозиторий превью публикуется только PNG выбранного этапа.
